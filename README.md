# Runtime Behavioral Models for LLM-Driven Microservice Decomposition

## Overview

This project investigates whether runtime-derived behavioral models can improve the quality of microservice decompositions generated by Large Language Models (LLMs).

Behavioral information was extracted through dynamic analysis and provided to the LLM as an additional input during the decomposition process.

The study evaluates the impact of different behavioral representations on decomposition quality across multiple monolithic applications.

---

## Research Question

> Does the inclusion of runtime-derived behavioral models improve the quality of LLM-generated microservice decompositions?

Additionally:

> Which behavioral representation provides the most effective augmentation?

---

## Behavioral Models Evaluated

The following runtime-derived models were generated and evaluated:

- Directly-Follows Graph (DFG)
- Generalized Finite State Machine (GFSM)
- Petri Net (Inductive Miner)
- BPMN (Split Miner)

## Results

The generated decompositions were evaluated using:

- CiD
- CMod
- BCP
- DI
- DTP
- LC
- MoJoFM

### Key Findings

- Runtime-derived behavioral information can influence decomposition quality.
- The impact of behavioral models is strongly repository-dependent.
- DFG provides the most consistent improvements across the evaluated systems.
- GFSM produces moderate improvements on selected repositories.
- Split Miner does not consistently improve decomposition quality.
- Improvements are more evident in internal quality metrics than in similarity to the reference decomposition.
